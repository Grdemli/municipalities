# Georgia Municipality Tracker

A simple, interactive web tool to track and visualize the municipalities you have visited in Georgia. 

## Features
* Click on municipalities or search by name to mark them as visited.
* Visual map that highlights visited areas.
* Generates a downloadable JPG of your custom map.
